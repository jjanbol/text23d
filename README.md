# text23d
The ability to generate realistic and complex 3D shapes2 from various inputs, such as text prompts or 2D im-ages, promises to streamline artistic and design pro-4 cesses, offering creators powerful new tools and workflows. The potential of 3D generative AI to democratize the creation of 3D content, making advanced tools accessible to a broader audience, further amplifies8 its significance across industries like gaming, education, retail, and interior design. Our analysis will cover10 experimenting with custom made text to 3D pipelines using state of the art architectures using mesh generation, BREP generation, NURBS/spline generation, BIM generation, and other novel pipelines that represent cutting-edge developments in the field, such as those utilizing diffusion and transformers models.
